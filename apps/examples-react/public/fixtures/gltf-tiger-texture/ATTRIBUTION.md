# Ghostscript tiger raster texture fixture

`ghostscript-tiger-fallback.png` is a 256×256 raster derivative of
`Ghostscript Tiger.svg` by Ghostscript authors, derived from GPL Ghostscript
`tiger.eps`.

Source: https://commons.wikimedia.org/wiki/File:Ghostscript_Tiger.svg

License: AGPL-3.0-or-later.

The generated glTF card uses the PNG as its core image source.
