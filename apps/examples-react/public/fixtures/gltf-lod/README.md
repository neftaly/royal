# Royal glTF LOD fixtures

`royal-four-step-color-lod-cube.gltf` is a locally generated fixture for the
examples app. It is a single cube mesh using material-level `MSFT_lod` with four
color steps:

- LOD0 red
- LOD1 amber
- LOD2 blue
- LOD3 graphite

The buffer data is embedded as a data URI so the fixture is self-contained.
